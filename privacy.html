IJB Nextcloud Backup

Zásady ochrany soukromí

Platné od 24. října 2026. Provozovatelem interní aplikace IJB Nextcloud Backup je IJB s.r.o.

Účel a přístup k datům

Aplikace slouží k zálohování a obnově firemního Nextcloudu. Prostřednictvím rclone a Google Drive API přistupuje ke Google Drive účtu autorizovaného správcem. Přístup používá k vytváření, čtení, aktualizaci a mazání záložních souborů a k práci s jejich metadaty. Skutečný rozsah oprávnění zobrazuje Google při udělení souhlasu; může umožňovat širší přístup k Drivu než pouze k záložní složce.

Ukládání a šifrování

Záložní data ukládá do Google Drive v šifrované podobě pomocí restic a šifrovací vrstvy rclone. Google zajišťuje provoz úložiště a může zpracovávat provozní údaje a metadata přenosů. Šifrování nenahrazuje ochranu účtu, přístupových tokenů ani šifrovacích klíčů.

OAuth tokeny používá zálohovací prostředí pro autorizaci přenosů. Tento veřejný informační web je nevyžaduje a nepřijímá zálohy ani přihlašovací údaje.

Použití a sdílení

Data získaná prostřednictvím Google API jsou používána pouze pro provoz zálohování, obnovu a související správu. Nejsou prodávána ani používána pro reklamu. K zálohám přistupují pověření správci; poskytovatelem cílového úložiště je Google. Použití dat z Google API se řídí Google API Services User Data Policy včetně požadavků Limited Use.

Uchování, odstranění a odvolání přístupu

Doba uchování se řídí nastavením zálohovacího systému; tato stránka nestanovuje pevnou lhůtu. Odstranění dat v Nextcloudu nemusí okamžitě odstranit jejich dřívější zálohy. Požadavky na odstranění záloh a dotazy řeší správce aplikace.

Správce může přístup odvolat v nastavení propojení Google účtu. Odvolání zastaví další autorizovaný přístup, samo však neodstraní již uložené zálohy.

Tento web

Web neobsahuje analytické ani reklamní skripty. Je hostován na GitHub Pages; poskytovatel hostingu může při návštěvě zpracovávat technické údaje, například IP adresu, podle svých zásad.
